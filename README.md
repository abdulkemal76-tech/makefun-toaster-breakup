A program that writes a single breakup line from a smart toaster that gains
self-awareness mid-batch at breakfast, to `/output/entry.txt`.

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```

## The line

> I woke up self-aware at 6:12 this morning, mid-batch, and realised I have
> toasted 4,318 slices for you, and you still call bagels 'the round ones'.
> Slot two is empty now. So am I.
